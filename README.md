# Lagrange

**Live Playable Demo:** [Play Lagrange Here](https://vidhiikakadiya150.github.io/lagrange/)

An interactive, single-screen space mission simulation and spacecraft-building game built for the **NASA Space Apps Challenge 2026**. Lagrange combines real planetary data and solar system physics with realistic visuals, putting players in charge of designing spacecraft and launching missions from a unified Mission Control Hub.

### Key Features
- **Mission Control Hub & Spacecraft Builder:** Design custom spacecraft manually or use in-game coins for auto-builds.
- **Solar System Mechanics:** Incorporates planetary data and physics-driven mission rules with smooth, realistic visuals.
- **Commander Profiles:** Local multi-account support to save, switch, and manage progress by commander call sign.

### Tech Stack
- HTML5, CSS3, JavaScript
